# Starlight Layout Specifications

This directory contains Starlight layout specifications written in the style of
CSS/W3C layout modules. They describe the current non-deprecated behavior that
the layout engine is expected to implement after style resolution.

- [Starlight Linear Layout Module Level 1](linear-layout.md)
- [Starlight Relative Layout Module Level 1](relative-layout.md)

These documents are implementation-facing specifications, not CSSWG
specifications. They use CSS terminology where it is useful, but Starlight
`display: linear` and `display: relative` are Lynx/Starlight layout modes.
